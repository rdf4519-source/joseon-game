# 조선 왕조 경영 (프로토타입)

Notion의 「국가 운영 시스템 GDD — 초안 01」을 기준으로 만든 HTML 기반 역사 국가 경영 시뮬레이션의 첫 뼈대입니다.
빌드 도구 없이 순수 HTML + CSS + JavaScript(ES 모듈)만 사용합니다.

## 실행 방법

ES 모듈은 `file://`로 직접 열면 동작하지 않으므로 로컬 서버로 엽니다.

```bash
# 둘 중 하나
python3 -m http.server 8000
npx http-server -p 8000
```

브라우저에서 <http://localhost:8000> 접속 → **스페이스바**로 시간 진행/정지.

## 폴더 구조

```
index.html            진입 HTML
css/style.css         스타일
js/
  main.js             화면 연결, 키 입력
  game.js             시간 루프 (일 단위 tick, 월 단위 정산)
  state.js            게임 상태 생성·저장·불러오기
  config.js           밸런스 수치 (임시값)
  assets.js           초상화·이미지·소리 로더 (파일 없으면 대체)
  systems/            순수 게임 규칙 — UI를 모름
    economy.js        경제·세금·재정 적자
    war.js            출병·전투·주둔·적 AI
    court.js          조정 안건·사건·민심·변란·암살
  ui/                 화면 그리기 — 규칙은 systems/ 호출
data/                 시나리오·건물·정사·사건 데이터
assets/               초상화·소리·이미지 (assets/README.md 참고)
```

**원칙:** 규칙(`systems/`)과 화면(`ui/`)과 데이터(`data/`)를 분리했습니다. 새 사건·정사·건물·인물은 대부분 `data/` 파일만 고치면 추가됩니다.

## 이미지·소리 추가

`assets/README.md` 참고. 예: `assets/portraits/taejong.png`를 넣으면 가족 화면에 태종 초상화가 바로 나옵니다.
소리는 `assets/sounds/battle.mp3` 등을 넣으면 합성음 대신 재생됩니다.

## 다음 단계 제안 (순서대로)

1. **플레이 테스트 → `config.js` 수치 조정.** 지금 한 판을 끝까지 해 보면서 재미없는 지점을 찾는 것이 가장 중요합니다.
2. **실제 지도.** 지금은 지역을 점으로 그린 추상 지도입니다. 영토·지도 GDD가 정해지면 지역 경계를 SVG `path`로 그리거나 지도 이미지 위에 같은 좌표로 얹습니다 (`js/ui/map.js`의 `drawMap`).
3. **시작 시점 확정** (1388 위화도 회군 vs 1401 태종). 새 시나리오는 `data/` 안에 파일을 하나 더 만들면 됩니다.
4. **실록 카드** — 실제 실록 원문·출처를 사건 데이터에 연결.
5. 왕위 계승·정란, 무역(도로·상인 이동 표시), 해군 순으로 확장.
6. 코드가 커지면 TypeScript + Vite 도입을 검토 (지금 구조를 그대로 옮길 수 있음).
